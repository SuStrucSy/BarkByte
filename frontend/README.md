# Timverse Frontend

The frontend is the browser application for Timverse. It lets users search specimen records, view specimen details, compare records, explore dashboard charts, submit data, and use account/admin workflows.

It is built with React, TypeScript, Vite, TanStack Router, React Query, Tailwind CSS, and shadcn/ui-style components.

## Local Development

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

The app runs at:

```text
http://localhost:5173
```

For the full local stack, including the backend and database, use the instructions in the root [README.md](../README.md) or [development.md](../development.md).

## Environment

The frontend reads configuration from Vite environment variables.

```text
VITE_API_URL=http://localhost:8000
```

`VITE_API_URL` is the base URL for the backend API. In local development, this is usually `http://localhost:8000`.

## Useful Commands

```bash
npm run dev
npm run build
npm run preview
npm run check
npm run lint
npm run format
npm run generate-client
```

- `dev` starts the local Vite server.
- `build` creates the production frontend build.
- `preview` serves the built app locally.
- `check`, `lint`, and `format` run Biome checks or formatting.
- `generate-client` regenerates the API client from `openapi.yaml`.

## Project Structure

- `src/routes`: Route definitions and page-level views.
- `src/components`: Reusable UI and feature components.
- `src/api`: Generated API client, endpoint functions, and API models.
- `src/hooks`: Shared React hooks.
- `src/lib`: Shared utilities, schemas, analytics, and constants.
- `src/assets`: Images, icons, and branding assets.
- `src/styles`: Global styles and theme files.

## API Client

The frontend talks to the FastAPI backend through a generated client. The client is generated by Orval from `frontend/openapi.yaml`.

When backend API contracts change, refresh the OpenAPI file from the running backend, convert it to YAML, and regenerate the frontend client:

```bash
cd frontend
curl http://localhost:8000/api/v1/openapi.json -o openapi.json
npx --yes @redocly/cli bundle openapi.json --output openapi.yaml
npm run generate-client
rm openapi.json
```

This updates generated files in:

- `src/api/endpoints`
- `src/api/model`

The generated client uses React Query and Axios, with the shared Axios instance in `src/api/mutator/custom-instance.ts`.

If `frontend/openapi.yaml` is already current, you can regenerate the client directly:

```bash
npm run generate-client
```

This keeps frontend request and response types aligned with the backend.
